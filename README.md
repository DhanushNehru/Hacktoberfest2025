## 🎉 Welcome!

**Hacktoberfest** is an annual event that encourages everyone to contribute to open source. Whether you’re a beginner or a seasoned developer, this project is perfect for your first pull request!

- **Register [here](https://hacktoberfest.com)** and make four pull requests (PRs) between October 1st–31st to earn free swag!
- Support open source and grow your skills.

## 🚀 Getting Started

### 1. Fork & Clone

- **Fork** this repository (top right corner).
- **Clone** your fork:
  ```bash
  git clone https://github.com/<your-github-username>/Hacktoberfest
  cd Hacktoberfest
  ```

### 2. Set Upstream Remote

```bash
git remote add upstream https://github.com/DhanushNehru/Hacktoberfest.git
```

### 3. Create a New Branch

```bash
git checkout -b your-branch-name
```

### 4. Make Your Changes

- Add your profile image to `static/images/`
- Add your profile data to `content/participant/`
- Or add your code to the appropriate language folder in `Add Code Here/`

### 5. Stage & Commit

```bash
git add <your-files>
git commit -m "Add <your changes>"
```

> ⚠️ Avoid committing `package.json` or `package-lock.json`.  
> ⚠️ Stage only the files you changed.

### 6. Push & Create Pull Request

```bash
git push origin your-branch-name
```

- Go to your fork on GitHub and click **"Compare & pull request"**.

## 📝 Contribution Guidelines

1. **Add Your Profile Picture**

   - Place a square PNG/JPG (min 544x544px) in `static/images/`:
     ```
     static/images/<YOUR-USERNAME>.png
     ```

2. **Add Your Profile Info**

   - Create a markdown file in `content/participant/`:
     ```
     content/participant/<YOUR-USERNAME>.md
     ```
   - Use this template:
     ```
     ---
     name: YOUR NAME
     institution/company: INSTITUTION_NAME
     github: USERNAME
     ---
     ```

3. **Add Your Code (Optional)**

   - Place your code in the relevant language folder:
     ```
     Add Code Here/PYTHON/<YOUR-FILENAME>.py
     Add Code Here/C++/<YOUR-FILENAME>.cpp
     ```

4. **Wait for your PR to be reviewed and merged.**

5. **Celebrate!** 🎉

## ⭐ Tips for Hacktoberfest

- Make more than 4 PRs to be safe (some may not count).
- You can contribute to your own repo if it has the `hacktoberfest` topic.
- Check that the repository is not excluded from Hacktoberfest.
